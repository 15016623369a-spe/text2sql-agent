# V2 检索漏表与自动补注修复

## 复测口径

检索规则用固定的 50 道开发题调试。定稿后，分别在原 200 道留出题和此前未用的 250 道题上测量。三个集合互不重叠，数据库都来自同一个 BIRD 快照。每题以 SQLite 准备参考 SQL 时读取的实体表和列为准。参考 SQL 只在本地评分，检索只接收题目和官方证据。此项评测无需模型请求。

Recall@K 衡量 BM25 初筛的覆盖率，分母为所有题中参考 SQL 读取的表或列数之和。最终召回率在补齐证据表和声明外键路径后计算。另统计至少漏一张参考表的题数，反映需要完整 JOIN 路径的题有多少受影响。

## 发现与改动

原 Top-4 加外键桥接后，开发集仍有 **7/50** 道题缺表，原留出集有 **23/200** 道，覆盖五个数据库。第 250 题的 `races` 和 `circuits` 分别排第五、第六。原桥接只连接入选的表，路径里缺少赛道这一端时，已有种子之间的最短路径无须经过两张参考表。

当前默认保留 BM25 Top-4，最多补三个有独立证据的候选表。证据来自题目或证据中的表名，以及小型外键目标表中精确匹配的短文本词组。字典匹配只在本地运行，额外输出限于命中的列名和对应表的 DDL。再沿已声明外键补齐最短路径。第 250 题的 `circuits.country` 命中后，桥接补回了 `races`，参考三表和所读列均进入提示。第 353 题的 `gender`、`race` 也被补回。

## 默认 K=4 的结果

- **开发 50 题。** BM25 表 Recall@4 为 **87.29%**、列 Recall@4 为 **90.06%**。最终表召回 **92.37% → 100%**，列召回 **93.98% → 100%**，缺表题 **7 → 0**。
- **原留出 200 题。** BM25 表 Recall@4 为 **89.17%**、列 Recall@4 为 **91.45%**。最终表召回 **94.48% → 98.09%**，列召回 **95.54% → 98.27%**，缺表题 **23 → 8**。DDL 文本字节比原 V2 增加 **3.03%**，仍比完整 schema 少 **18.26%**。
- **此前未用 250 题。** BM25 表 Recall@4 为 **89.55%**、列 Recall@4 为 **90.87%**。最终表召回 **95.30% → 98.95%**，列召回 **96.04% → 99.04%**，缺表题 **24 → 6**。DDL 文本字节比原 V2 增加 **3.93%**，仍比完整 schema 少 **16.26%**。

在此前未用的 250 题上，K 为 2、3、4、5、6 时，新检索的最终表召回分别是 **92.51%、97.04%、98.95%、99.30%、99.65%**。K=4 仍有 6 道题不全，其中 5 道来自 Formula 1。召回衡量提示是否包含参考表列，整体 EX 需另跑模型评测。DDL 字节衡量结构提示的体积。

## 自动补注的两个修复

- **118。** 本地 `posts.LastEditorDisplayName` 的 256 行样本中只有 2 行有值。自动补注把有值比例不超过 5% 的描述性候选从普通问题中筛出。查询明确问缺失或引用确切字段时仍保留该字段及采样提示。若稀疏列的角色前缀能对应唯一的声明外键，且目标表有同名后缀的可用字段，则给出实际关联路径。该题提示改为 `posts.LastEditorUserId → users.Id` 后读取 `users.DisplayName`。
- **353。** 「平均每个实体有多少关联项」优先从符合条件的实体集合出发。命中唯一的实体到关联表路径时，提示按实体计数，除非题意要求有匹配，否则保留零计数，并筛去仅在实体词上相似的旁支补注。该题从 `superhero` 出发，以 `LEFT JOIN hero_power` 保留 3 位符合条件但没有关联的英雄。

用旧自动版归档提示和新版端到端提示，在同一 `deepseek-flash`、温度 0 下交错重放，每题每版各 5 次。两题均从 **0/5 → 5/5**。118 的检索表未变，353 同时受益于检索补表和实体范围提示。这两道开发题的重放用于回归验收。250 本次验证检索覆盖，未单独调整该题补注。人工补注规则保留，修复用于自动补注路径。

## 复现

```bash
python -m unittest discover -s tests -v
python -m evaluation.run_schema_recall --split dev
python -m evaluation.run_schema_recall --split eval
python -m evaluation.run_schema_recall --split unused --top-k 2 3 4 5 6
```

离线评测可加 `--output` 保存新旧逐题数据。原 10 项与本次新增 3 项共 **13/13** 通过。
